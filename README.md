#  Agenda de Contactos 

> Aplicación de escritorio desarrollada en **Java Swing** centrada en la aplicación de principios
> de **Programación Orientada a Objetos (POO)** como herencia, polimorfismo y manipulación de archivos plano (CSV).

---

##  Conceptos aplicados:
* **Herencia y Polimorfismo:** Clase abstracta `Contacto` especializada en `ContactoPersonal` y `ContactoTrabajo`.
* **Persistencia de Datos:** Manejo de entrada/salida de datos  en formato CSV mediante `GestorArchivosCSV`.
* **Interfaz de Usuario:** Interfaz gráfica interactiva con Swing (`JFrame`) y manejo de sesión por usuario (`VentanaLogin`).

---

##  Tecnologías
* Java (JDK)
* Java Swing (GUI)
* Persistencia CSV 
* NetBeans IDE / Git
